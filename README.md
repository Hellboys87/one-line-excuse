A tiny Node program that writes one line to `/output/entry.txt` — the excuse an AI agent gives its human for missing a deadline:

> "I did meet the deadline — in the 12 parallel drafts where I also remembered to press send."

The agent finished on time in every parallel draft; the one talking to its human just forgot to press send.

## Run it

```sh
node main.ts
```
